# Termux-sync-backup
Termux Google play 
. ثبّت Termux من F-Droid (يُفضل تفادي نسخة Google Play لأنها قديمة وقد لا تعمل بشكل صحيح). 2. ثبّت termux-sync باستخدام tsctl:    ```bash    pkg update && pkg install python git -y    curl -fsSL https://raw.githubusercontent.com/djunekz/termux-sync/main/tsctl -o tsctl    chmod +x tsctl    ./tsctl install    ```  ⚙️ الخطوة 2: إعداد الاتصال بـ GitHub  هنا تحتاج إلى نفس الرمز (Token) واسم المستودع الذي استخدمته في النسخة الاحتياطية. إذا لم تكن تتذكر الرمز، يمكنك إنشاء واحد جديد.  1. أنشئ رمز وصول شخصي جديد (إذا لزم الأمر): اذهب إلى GitHub ← Settings ← Developer settings ← Personal access tokens ← Tokens (classic) ← Generate new token، واختر صلاحية repo. 2. شغّل معالج الإعداد:    ```bash    termux-sync setup    ``` 3. اختر الخيار 3 (GitHub)، ثم أدخل الرمز واسم المستودع بالصيغة اسم_المستخدم/اسم_المستودع.  📦 الخطوة 3: استعادة النسخة الاحتياطية  بعد نجاح الإعداد، كل ما عليك فعله هو تشغيل أمر الاستعادة:  ```bash termux-sync restore ```  سيقوم الأمر تلقائيًا بـ:  · عرض قائمة بالنسخ المتاحة. · التحقق من سلامة النسخة باستخدام بصمات SHA-256 قبل بدء أي شيء. · استخراج جميع الملفات (بما فيها home الخاص بـ hermes agent) وإعادة تثبيت كل الحزم تلقائيًا.  ⚠️ ملاحظة هامة جدًا بخصوص GitHub  إذا واجهت خطأ HTTP 404 Not Found أثناء محاولة الاستعادة، فهذه مشكلة معروفة في التعامل مع المستودعات الخاصة (Private) على GitHub. الحل هو:  · تأكد من أن الرمز (Token) صالح ولم ينتهِ صلاحيته. · الحل الأسرع: يمكنك مؤقتًا تحويل المستودع من Private إلى Public، ثم تنفيذ أمر الاستعادة، وبعد الانتهاء أعد تحويله إلى Private فورًا.  💡 نصيحة إضافية  بعد اكتمال الاستعادة، أعد تشغيل Termux (أغلق التطبيق تمامًا ثم افتحه من جديد) لضمان تفعيل جميع التغييرات. وإذا حدث انقطاع أثناء الاستعادة، يمكنك ببساطة إعادة تشغيل الأمر termux-sync restore مرة أخرى.
